# Korea Electricity Bill Calculator (한국 전력 요금 계산기)

Homey 앱으로 한국전력(KEPCO) 누진제 요금 체계를 기반으로 전기 요금을 계산합니다.

## 주요 기능

### 실시간 요금 계산
- 한국전력 주택용 전기요금 누진제 계산 (저압/고압)
- 계절별 요금 자동 적용 — 주택용은 하계 7~8월 / 동계 12~2월 / 기타계절, 비주택용은 여름철 6~8월 / 겨울철 11~2월 / 봄·가을철 3~5월·9~10월
- 검침일 기준 청구기간 자동 계산, 계절이 걸치면 일수로 안분
- 대가족·복지 할인, 태양광 상계, 월 목표 예산 대비 추적

### 지원 계약종별
주택용(누진) 외에 정액(계절별 단일요율)과 시간대별(TOU) 종별도 지원합니다. 비주택용 종별은 **계약전력(kW)** 입력이 필요합니다.

- **주택용** (저압 / 고압) — 누진제
- **일반용(갑)Ⅰ** (저압 / 고압A·B, 선택Ⅰ·Ⅱ)
- **교육용(갑)** (저압 / 고압A·B, 선택Ⅰ·Ⅱ)
- **산업용(갑)Ⅰ** (저압 / 고압A·B, 선택Ⅰ·Ⅱ)
- **농사용(갑)**, **농사용(을)** (저압 / 고압)
- **심야전력(갑)** (월 최저요금 적용)
- **일반용(갑)Ⅱ**, **산업용(갑)Ⅱ** (고압A·B, 선택Ⅰ·Ⅱ) — **시간대별(TOU)**

> **시간대별(TOU) 요금제**는 설치 이후 실시간 사용량을 경/중/최대부하로 집계해 계산합니다. 설치 후 **첫 완전한 청구기간부터** 정확하며, 미터 보고 시점 기준 근사입니다. 경부하 22-08시, 여름·봄가을 최대부하 15-21시, 겨울 최대부하 09-12·16-19시.
>
> 한전 **토요일·공휴일 계량 특례**도 적용합니다(임시공휴일 제외). 토요일은 최대부하 사용량을 중간부하로, 공휴일(일요일 포함)은 전 시간대를 경부하로 계량합니다. 설날·추석·부처님오신날 등 음력 공휴일과 대체공휴일은 자동 계산되며, 임기만료 선거일은 확인된 날짜만 반영합니다.
>
> **미지원 종별**: 일반용(을)·교육용(을)·산업용(을), 심야전력(을)Ⅰ·Ⅱ, 주택용 계시별(제주), 가로등, 전기차 충전전력, 재생에너지·보완전력·분산에너지 부족전력.
>
> '을' 종별(계약전력 300kW 이상)은 대형 빌딩·공장용이라 홈오토메이션 범위 밖이기도 하지만, 기술적으로도 기본요금을 계약전력이 아니라 **요금적용전력**(당월 포함 직전 12개월 최대수요전력, 하한은 계약전력의 30%)으로 매겨서 최대수요전력 추적이 필요합니다. 이 앱은 `기본요금 = 단가 × 계약전력`만 계산합니다. 선택Ⅲ 요금제도 지원 대상이 아닙니다. 일반용(갑)Ⅱ의 선택Ⅲ·Ⅳ는 '26.12월 시행 예정이라 아직 반영하지 않았습니다.

### 할인 제도 지원 (주택용 전용)

| 할인 | 내용 | 월 한도 (기타계절 / 하계) |
|------|------|--------------------------|
| **대가족·출산·3자녀** | 전기요금의 30% | 16,000원 / 20,000원 |
| **생명유지장치** | 전기요금의 30% | 한도 없음 |
| **유공자·장애인** | 정액 감면 | 16,000원 / 20,000원 |
| **사회복지시설** | 전기요금의 30% | — |
| **기초생활(생계·의료)** | 정액 감면 | 16,000원 / 20,000원 |
| **기초생활(주거·교육)** | 정액 감면 | 10,000원 / 12,000원 |
| **차상위계층** | 정액 감면 | 8,000원 / 10,000원 |

대가족 할인과 복지 할인은 원칙적으로 **더 큰 쪽 하나만** 적용됩니다. 다만 기초생활수급자·차상위계층은 대가족 할인과 중복 적용됩니다.

### Flow 자동화

#### 트리거 (When...)
- **누진 단계 변경**: 누진 단계가 변경되었을 때 (예: 1단계 → 2단계, 검침일 초기화 포함)
- **누진 단계 상승**: 누진 단계가 올라갈 때만 (검침일 초기화로 내려갈 때는 제외)
- **새 청구기간 시작**: 검침일에 새 청구기간이 시작될 때 (지난 청구기간 사용량·요금 토큰 제공)
- **예상 요금 예산 초과**: 이번달 예상 요금이 월 목표 예산을 처음 넘어설 때
- **요금 금액 초과**: 이번달 사용량 요금이 지정 금액을 처음 넘어설 때

#### 조건 (And...)
- **이번달 사용량 요금이 금액을 초과**: 현재까지 발생한 요금 기준 (월말 예상 요금이 아님)
- **현재 부하시간대**: 지금이 경/중/최대부하 시간대인지 확인 (고전력 기기 경부하 이동 자동화)
- **누진 단계 N 이상**: 현재 누진 단계가 지정 단계 이상인지 확인 (4단계=슈퍼유저 경고 등)

## 요금 체계

내장 요율은 한국전력 **2026년 6월 1일 시행** 요금표 기준입니다. 원본은 `docs/2026_kr_bills.pdf`에 있고, 요율 데이터는 `lib/rates_korea.json`에 있습니다.

### 주택용 누진 구간 (기타계절: 1/1~6/30, 9/1~12/31)

| 구간 | 사용량 | 저압 기본 / 전력량 | 고압 기본 / 전력량 |
|------|--------|--------------------|--------------------|
| 1단계 | ~200kWh | 910원 / 120.0원 | 730원 / 105.0원 |
| 2단계 | 201~400kWh | 1,600원 / 214.6원 | 1,260원 / 174.0원 |
| 3단계 | 400kWh 초과 | 7,300원 / 307.3원 | 6,060원 / 242.3원 |

### 하계 (7/1~8/31)

| 구간 | 사용량 | 저압 기본 / 전력량 | 고압 기본 / 전력량 |
|------|--------|--------------------|--------------------|
| 1단계 | ~300kWh | 910원 / 120.0원 | 730원 / 105.0원 |
| 2단계 | 301~450kWh | 1,600원 / 214.6원 | 1,260원 / 174.0원 |
| 3단계 | 450kWh 초과 | 7,300원 / 307.3원 | 6,060원 / 242.3원 |

**슈퍼유저요금**: 하계(7/1~8/31)와 동계(12/1~2월 말일) 1,000kWh 초과분은 저압 736.2원/kWh, 고압 601.3원/kWh를 적용합니다.

청구기간이 두 계절에 걸치면 계절별 사용일수로 안분해 계산합니다. 예를 들어 검침일이 8일이면 6/9~7/8 기간은 기타계절 22일 + 하계 8일로 나뉩니다.

### 부가 요금
- 기후환경요금 9.0원/kWh
- 연료비조정액 +5.0원/kWh (±5원 상한)
- 부가가치세 10%
- 전력산업기반기금 2.7% (2025.7.1 3.2%→2.7% 인하)

> 기후환경요금·연료비조정 단가는 앱에 내장된 값을 자동 사용합니다. 한전이 앱 업데이트 전에 요율을 바꾸면 디바이스 설정에서 '내장 요율 자동 사용'을 끄고 직접 입력할 수 있습니다.

## 설치 방법

1. Homey 앱에서 "Korea Electricity Bill Calculator" 검색
2. 앱 설치
3. 디바이스 추가 시 `meter_power` capability가 있는 전력 미터 기기 선택
4. 설정에서 검침일, 계약종별(비주택용은 계약전력도), 전압 구분, 할인 옵션 설정

### 설치 후 권장 설정 (미터값 기준점)

이 앱은 소스 기기의 **누적 사용량(meter_power)** 을 읽어, 검침일·연초 대비 사용량을 계산합니다. 최초 설치 시 월초·연초 미터값이 **현재 값으로 자동 설정**되므로, 설치 시점부터 0에서 사용량이 시작됩니다.

정확한 이번달/올해 사용량을 원한다면, 디바이스 **고급 설정**에서 아래 값을 직접 입력하세요:

- **월초(검침일) 미터값**: 지난 검침일 당시 전력량계 미터값 (kWh)
- **연초 미터값**: 1월 1일 당시 전력량계 미터값 (kWh)

> 월 중간에 설치했다면 이 값을 입력해야 검침일 기준 이번달 사용량이 정확히 계산됩니다. 값을 모르면 그대로 두어도 되며, 다음 검침일/연초부터는 자동으로 정확해집니다.

## 설정 옵션

### 한전 설정
| 설정 | 설명 | 기본값 |
|------|------|--------|
| 검침일 | 한전 검침일 (1-31, 0은 말일) | 1 |
| 계약종별 | 주택용 / 일반용(갑)Ⅰ·Ⅱ / 교육용(갑) / 산업용(갑)Ⅰ·Ⅱ / 농사용(갑)·(을) / 심야전력(갑) | 주택용 |
| 전압 구분 (주택용 전용) | 저압(단독주택) / 고압(주로 아파트) — 계약종별이 '주택용'일 때만 사용 | 저압 |
| 계약전력 (kW) | 비주택용 종별의 기본요금 계산에 필요 (기본요금 = 원/kW × 계약전력). 주택용·심야전력(갑)은 0 | 0 |
| 월 목표 예산 (원) | 예산 대비(%) 센서와 '예상 요금 예산 초과' 트리거에 사용. 0이면 비활성화 | 0 |
| 내장 요율 자동 사용 | 기후환경요금·연료비조정 단가를 내장 최신값으로 자동 사용 (끄면 수동 입력) | ON |
| 기후환경요금 단가 (원/kWh) | 자동 해제 시 사용 | 9.0 |
| 연료비조정 단가 (원/kWh) | 자동 해제 시 사용 (±5 상한) | 5.0 |
| 송전(태양광) 사용량 차감 | 소스의 송전량(meter_power.exported)을 차감해 순사용량으로 계산 (상계 근사, TOU 제외) | OFF |


|--------|------|
| `bill-known-values` | 한전 요금표에서 손계산한 값과 대조 (구성요소·누진 경계·슈퍼유저·계절 걸침·할인·TOU 단가) |
| `bill-golden` | 계약종별 × 계절 × 누진 경계 × 할인 68,172 케이스의 계산 결과를 해시로 고정 |
| `kr-holidays` | 공휴일·대체공휴일 판정을 2023~2026년 실제 달력과 대조 |
| `tou-period` | 부하시간대 구분 + 토요일·공휴일 계량 특례 |
| `money-today` | '오늘 쓴 요금'의 자정 리셋·검침일 이월·태양광 상계 하한 |
| `capabilities` | 앱 업데이트 시 센서 자동 추가와 순서 동기화 |

`money-today`·`capabilities`·`tou-period`는 `require('homey')`를 스텁으로 바꿔 **실제 `device.js`를 그대로 구동**합니다 (로직을 테스트에 다시 옮겨 적으면 원본과 어긋나므로).

요율표(`lib/rates_korea.json`)나 계산 로직을 의도적으로 바꾸면 `bill-golden`이 깨집니다. 변경 내용을 확인한 뒤 `npm run test:golden:update`로 기준값을 갱신하고, 무엇이 왜 바뀌었는지 커밋 메시지에 남기세요.
